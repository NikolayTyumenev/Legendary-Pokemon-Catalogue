# Legendary & Mythical Pokemon Catalogue

A comprehensive web-based catalogue featuring 101 Legendary and Mythical Pokemon from all 9 generations, with advanced features including shiny variants, team building, and detailed stats analysis.

## Features

### Core Functionality
- **Browse & Search** - Filter by type, generation, classification with pagination
- **Detailed Pokemon Pages** - Complete stats, descriptions, lore, and abilities
- **Admin Panel** - Modern dashboard with statistics and management tools
- **Authentication System** - Secure login/logout with session management

### Challenge Features (DMIT2025 Requirements)
1. **Multi-Image Gallery** - Regular, shiny, and alternate form images with animated toggle
2. **Normalized Tagging System** - Separate tags and junction tables for flexible categorization
3. **Team Builder** - Custom feature for creating teams (up to 6 Pokemon) with:
   - Type distribution analysis
   - Team statistics overview
   - Weakness/resistance calculations

### UI/UX Enhancements
- ✨ Animated shiny toggle with sparkle effects
- 🎨 Bootstrap 5.3.7 with custom styling
- 📱 Fully responsive design
- 🎯 Icon-enhanced navigation (Bootstrap Icons)
- 🖼️ Optimized images (200px thumbnails, 720px full-size)

## Database Schema

- **Database**: `dmit2025`
- **Main Table**: `pokemon` (101 Legendary & Mythical Pokemon)
  - Includes: stats, types, classification, images, descriptions
  - Shiny images linked via `shiny_image` column
- **Authentication**: `group_3_catalogue_admin`
- **Connection**: mysqli via `private/connect.php`

### Key Tables
- `pokemon` - Main Pokemon data
- `group_3_catalogue_admin` - Admin user authentication
- (Additional tables for tags/junction as per challenge requirements)

## Data Sources

All Pokemon data sourced from official resources:

- **Serebii.net** - https://www.serebii.net/pokemon/legendary.shtml
  - Legendary & Mythical Pokemon lists
  - Base stats and abilities
  
- **Bulbapedia** - https://bulbapedia.bulbagarden.net/
  - Detailed lore and descriptions
  - Move sets and characteristics

- **PokeAPI GitHub** - https://github.com/PokeAPI/sprites
  - Official artwork and sprites
  - Shiny variant images

## Image Processing

Images are automatically processed on upload:
- **Thumbnails**: 200px width (for browse page)
- **Full-size**: 720px max width (for detail pages)
- **Formats**: JPG, PNG, GIF, WEBP supported
- **Transparency**: Preserved for PNG/GIF

## Development Notes
